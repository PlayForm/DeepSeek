# Changelog

All notable changes to this package will be documented in this file.

## 0.2.0

### Changed

- The D4-D8 release pass (the pack and trace libraries ship across both trees): the hook's source,
  its scheme and its bundle patch move with it.
- The role-prefix contract applied to the hook's ledger strings and manifest.
- Line endings normalised and the LICENSE text wrapped.
- The repository-wide markdown clean-up, the prettier reflow, and the README restructured onto the
  role / surfaces / ledger template.

## 0.1.0

### Changed

- The 0.1.0 family release: the package ships at 0.1.0 with the 31-package family, every
  `@playform/` sibling pin reads 0.1.0, and the role-prefix contract settles its
  `@playform/ets-hook-dsh-normalize-dash` identity.

## 0.0.1

### Added

- The initial release of @playform/ets-hook-dsh-normalize-dash: the stream hook normalizing the
  unicode dash family in model output (the Effect-TS release of the DeepSeek Harness Plugin Family).
