# Changelog

All notable changes to this package will be documented in this file.

## 0.3.0

### Changed

- The 0.3.0 release line: the manifest version, the `@playform/` sibling pins and the host
  devDependencies move together - the host line to `0.2.1-rc.4` and zod to 4.6.7.

## 0.2.0

### Added

- The Effect-TS trace library: the D4-D8 layer that ships with the family, with its build
  configuration and its README.

### Changed

- The D4-D8 release pass ships the pack and trace libraries across both trees; the package's
  manifest, build and documentation move with it.
- The prettier reflow across `Source`, `SCHEME.md`, `README.md` and `Target` keeps the compiled tree
  byte-identical to its sources.

## 0.1.0

### Changed

- No package-local history: the package does not exist in the 0.1.0 release and lands afterwards
  with the 2026-10-22 PoC delivery.
