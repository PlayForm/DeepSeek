# Observers-And-Waterfalls - the observers, the waterfalls and the deadline tests

The fs/observed stale-halt observer, the advisory bash intercept and the pre-step pass-through
waterfalls, the deadline overflow with the jobs hub and its typed jobId handle, and the presentation
purity.

## Scenarios

- O1: an external touch with a moved version flips the cell to halted stale with the byte-exact
  line, and the observer skips govern-marked writes, unchanged versions, and unknown paths in
  silence; it is a pure cell flipper with zero fs calls and a byte-stable presentation.
- O2: a bash command that mentions a held file gets the exact advisory offer and the byte-exact
  intercept line while the downstream decision passes through unchanged, and an unrelated command
  passes untouched.
- O3: the pre-step listener awaits next() first and passes the decision through unchanged.
- O4: with the deadline exceeded mid-commit the remainder continues as ONE background job (kind
  batch-edit-continue, label batch mach-1, owner agent-a) with the typed jobId in the output, and
  without a jobs hub the remainder halts with the deadline reason and the committed line counts the
  halt.
