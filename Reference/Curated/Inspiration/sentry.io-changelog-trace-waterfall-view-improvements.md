# Trace Waterfall View Improvements

June 26, 2025 - 1 min read

The Trace waterfall UX has been improved to show standalone spans like INP/CLS Spans.

We've also made changes to the span details panel to show a clear set of attributes that you can
search in the Trace Explorer as well.

You can also see the logs for the entire trace or a specific span as well.
