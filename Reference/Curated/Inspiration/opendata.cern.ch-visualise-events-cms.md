# CMS Event Display (iSpy WebGL)

## How to use the event display

The CMS event display (called iSpy) can be used to visualise in your browser collision data recorded
by the CMS detector. Files of a custom type called `.ig` can be opened using iSpy. Each `.ig` file
is in fact a collection containing numerous individual collision events.

This guide will take you through some of the basic functionality of the event display.

The detector visibility panel lists the toggleable detector elements: Tracker Barrels, Tracker
Endcaps, ECAL Barrel, ECAL Endcap (+), ECAL Endcap (-), HCAL Barrel, HCAL Endcaps, HCAL Outer, HCAL
Forward (+), HCAL Forward (-), Drift Tubes, Cathode Strip Chambers, Resistive Plate Chambers
(barrel), Resistive Plate Chambers (+), Resistive Plate Chambers (-), plus the Imported, Provenance,
Tracking and Physics groups. The status line reports the frame rate and render time (for example 23
FPS (5-23) and 34 MS (16-1398)).
