#  Goal

In this tutorial you will learn how to:

- Use the OpenCV function [cv::filter2D](../../d4/d86/group__imgproc__filter.html#ga27c049795ce870216ddfb366086b5a04) in order to perform some laplacian filtering for image sharpening
- Use the OpenCV function [cv::distanceTransform](../../d7/d1b/group__imgproc__misc.html#ga8a0b7fdfcb7a13dde018988ba3a43042) in order to obtain the derived representation of a binary image, where the value of each pixel is replaced by its distance to the nearest background pixel
- Use the OpenCV function [cv::watershed](../../d3/d47/group__imgproc__segmentation.html#ga3267243e4d3f95165d55a618c65ac6e1) in order to isolate objects in the image from the background
