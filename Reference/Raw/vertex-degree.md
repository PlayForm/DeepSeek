# Start Doing Graph Theory
## by Mikhail Lavrov
_Start Doing Graph Theory_ is an introductory textbook about using graph theory to solve puzzles, prove theorems, and everything in between. It is freely available (under a Creative Commons license) to read online or to download as a PDF file.
