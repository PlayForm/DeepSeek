# Start Doing Graph Theory

![](images/logo.png)

## by Mikhail Lavrov

\

*Start Doing Graph Theory* is an introductory textbook about using graph theory to solve puzzles, prove theorems, and everything in between. It is freely available (under a Creative Commons license) to read online or to download as a PDF file.
