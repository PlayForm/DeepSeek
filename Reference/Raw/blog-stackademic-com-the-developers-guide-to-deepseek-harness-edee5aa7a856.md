I made a rookie mistake the week DeepSeek Harness dropped. I assumed it was a new model, opened a tab to find the benchmarks, and found a repo instead.

I wasn’t the only one. People searching “deepseek harness” often expect a model review and land on launch coverage instead. The confusion is understandable, but the distinction matters, so here it is up front.
**DeepSeek Harness (dsh) is an open source agent runtime, not a model.** It is the code that sits between a language model and your filesystem, released under the MIT license. You install it, point it at a model, and it handles tools, sandboxing, sessions, and the agent loop. DeepSeek’s own shorthand is “Model + Harness = Agent.”
This guide covers what it is, how to run it, which preset to pick, and where it can bite you.
