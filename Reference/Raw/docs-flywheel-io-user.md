# Welcome to Flywheel
Flywheel is a research data platform that provides the tools needed for data import, automated curation, image processing, machine learning workflows, and secure collaboration.
Continue reading to learn more about how to get started in Flywheel as a [user](https://docs.flywheel.io/user/#getting-started-users), [administrator](https://docs.flywheel.io/user/#getting-started-site-admin) or [Gear developer](https://docs.flywheel.io/user/#getting-started-gear-developer).
## Signing In
To begin the process the user will need to sign into Flywheel. Each Flywheel site has their own unique URL.
For example: `https://yourinstitution.flywheel.io`.
Your institution's Flywheel site may be configured to allow using multiple different institutional and social credentials to sign in. Ask your Flywheel site admin if you are unsure of which authentication method to use. The Flywheel sign on page is displayed below.
Note
Your sign-in screen looks different depending on which authentication methods your site uses. On sites configured for National Institute of Standards and Technology (NIST) environments, a system use notification appears each time you visit the site, and you must acknowledge it before you can continue.
