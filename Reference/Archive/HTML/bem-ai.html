Data and formats

Composable

Components that compose into workflows.

A workflow is a graph of functions with one entry point, and the input is the call itself: an API request, an upload, or an email. Each component does one job, so when a result looks wrong you know which step to open. Guardrails elsewhere are markdown files. bem's are rails.

  1. 01

    Split

    Break a file that holds many documents into one document each.

  2. 02

    Classify

    Label each input and send it down the right path. Routing starts here.

  3. 03

    Extract

    Pull typed fields into the schema you define, each with a confidence score.

  4. 04

    Enrich

    Match against your reference data and add what your systems already know.

  5. 05

    Payload Shaping

    Reshape the JSON into the form your downstream system expects.

  6. 06

    Send

    Deliver the result to a webhook, an S3 bucket, or a Google Drive folder.

Also available: Parse for sections, entities, and relationships, Join for many inputs into one output, Render for a Word document from a template, and Evaluate to grade another function’s output. Decide applies your policies to extracted data.

Predictable

Built for work you can't afford to get wrong.

bem follows the defined process every time. Messy inputs vary, but the steps don't. Every field is versioned, audited, and confidence-scored, so failures surface as a review, not an incident.

Your build, our burden.

Decide combines extracted data with your policies and returns a decision with reasoning and a confidence score. It runs after Extract and Enrich. You write the policy. bem runs it on every record and keeps the receipt.
