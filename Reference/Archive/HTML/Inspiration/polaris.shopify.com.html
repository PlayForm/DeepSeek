Polaris references

Shopify apps can appear across multiple surfaces in the Shopify platform. Each surface has its own set of available APIs and components. For an overview of all surfaces and how to build apps for them, see Build apps for Shopify.

All app surfaces use Polaris, Shopify's unified UI framework built on web components, to deliver a consistent experience across the platform.

Learn more about using web components, including layouts, icons, how to handle events, and more.

Extensions in other surfaces

Extensions put your app's UI inside a surface that Shopify renders: actions and blocks on admin resource pages, defined points in checkout and customer accounts, and the smart grid and cart in Point of Sale. Each surface has its own extension APIs and its own subset of Polaris web components.
