Path System

Relevant source files
  • test/tests/Path_Intersections.js

The Path System is the core vector drawing capability in Paper.js, providing comprehensive functionality for creating, manipulating, and rendering vector paths. This system handles the representation of paths through segments and curves, supports path operations like joining and boolean operations, and offers utilities for path simplification and flattening.

For information about styling paths, see Styling System. For details on how paths fit into the scene graph, see Scene Graph.

Path Structure and Representation

The Path System is built around a hierarchy of classes with PathItem as the base class. Paths are represented as collections of segments (points with handles), connected by curves.

Sources: src/path/Path.js21-296 src/path/Curve.js27-145 src/path/PathItem.js22-34

Segments and Curves

A path consists of segments connected by curves. Each segment contains a point and optional handle points (handleIn and handleOut) that control the curvature.

Sources: src/path/Path.js170-257 src/path/Curve.js63-145

A curve in Paper.js is a cubic Bézier curve defined by four points:

  1. The point of the first segment
  2. The handleOut of the first segment
  3. The handleIn of the second segment
  4. The point of the second segment

Paths can be closed or open. When a path is closed, a curve connects the last segment back to the first segment.

// Example of a simple path with segments



var path = new Path();




path.add(new Point(30, 75));  // First segment




path.add(new Point(100, 20)); // Second segment




path.add(new Point(170, 75)); // Third segment




path.closed = true// Close the path

  4. Using predefined shape constructors:

Boolean Operations

One of the most powerful features of the Path System is the ability to perform boolean operations on paths:

  • Unite: Combines the area of two paths
  • Intersect: Keeps only the area where both paths overlap
  • Subtract: Subtracts the area of the second path from the first path
  • Exclude: Keeps only the area where the paths don't overlap

Boolean operations work by:

  1. Calculating the intersections between paths
  2. Splitting paths at these intersections
  3. Determining which parts to keep based on winding numbers and the operation type
  4. Creating a new path from the kept parts

Path Utilities

PathFitter

The PathFitter class is used to simplify paths by reducing the number of segments while maintaining the visual appearance as closely as possible. It uses the Ramer-Douglas-Peucker algorithm to fit cubic bezier curves to digitized points.

// Simplifying a path



var path = new Path(/* ... */);




path.simplify(0.5); // Tolerance parameter

Sources: src/path/PathFitter.js23-69 src/path/PathFitter.js114-217

PathFlattener

The PathFlattener class converts curves into sequences of straight lines by subdividing curves until they are flat enough according to a specified tolerance. This is useful for path measurement, hit testing, and other operations that are easier to perform on straight lines.

// Flattening a path



var path = new Path(/* ... */);




path.flatten(0.25); // Flatness parameter

Curve Operations and Classifications

Curves in Paper.js can be analyzed and manipulated in various ways:

Curves can be classified into different types based on their mathematical properties:

  • Line: A straight line
  • Quadratic: A quadratic bezier curve
  • Serpentine: Has an S-shape with one inflection point
  • Cusp: Has a sharp point with a discontinuous derivative
  • Loop: Self-intersects to form a loop
  • Arch: A simple, non-inflected curve

Performance Considerations

The Path System includes several optimizations for performance:

  1. Caching: Various properties like length and area are cached and only recalculated when necessary.
  2. Curve subdivision: Used for efficient hit testing and intersection detection.
  3. Path simplification: Reduces the number of segments for better performance.
  4. Collision detection: Uses broad-phase algorithms to quickly filter out non-colliding paths.

For complex paths or when working with many paths, consider:

  • Using simplify() to reduce the number of segments
  • Using flatten() with an appropriate tolerance for operations on complex curves
  • Using compound paths for complex shapes with holes
