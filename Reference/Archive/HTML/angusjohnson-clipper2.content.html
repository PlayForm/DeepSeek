Clipper2

Why there haven’t been any updates in the last 6 months

A Polygon Clipping, Offsetting library (in C++, C# & Delphi)

The Clipper2 library performs intersection, union, difference and XOR boolean operations on both simple and complex polygons. It also performs polygon offsetting. This is a major update of my original Clipper library that was written about 15 years ago. That library I'm now calling Clipper1, and while it still works very well, Clipper2 is just better.

Compilers

Clipper2 can be compiled using any one of three supported programming languages: C++, or C#, or Delphi Pascal. The library can also be accessed from other languages by dynamically linking to exported functions in the C++ compiled Clipper2 library. (The C++ compiled code is measurably faster so, where performance is critical, even C# and Delphi developers may prefer this approach in application development.)

Lang. Requirements
Requires C++17, or
The library uses Standard Library 2.0 but the sample code uses .NET6, or
Compiles with any version of Delphi from version 7 to current.
