# THE WORKSPACE FAMILY - THE OBSERVE HOOK

> This is a granular document of the Workspace Plugin Family Decomposition. The parent hub is
> Documentation/Plans/WORKSPACE-PLUGIN-FAMILY-DECOMPOSITION.md. THE FRAMING (binding): the workspace
> family is the DEEPSEEK HARNESS'S OWN REFACTORING into the WORKSPACE-CENTRIC RUNTIME, powered by
> the @playform plugin family, and never a single plugin.

---

- **THE PACKAGE**: `@playform/hook-dsh-workspace-observe`, the EVENT HOOK.
- **THE ROLE** (the family map): the revisions, the observe-stamps, and the origin records, which
  make the FIRST step of the invisible flow.
- **THE ORCHESTRATION POSITION**: "the observe stamps" opens the flow: the observe stamps -> the
  semantics resolve -> the operate proposes -> the govern gates -> the authority licenses -> the
  approve binds -> the merge commits -> the journal records -> the audit lines -> the live view
  presents. All of it is evented by the plugin system (fs/observed, the tools' waterfalls, the
  lifecycle) and all of it is governed by the plugin harness.
- **THE VISIBILITY RULE**: the stamps are the INVISIBLE plugin flow, and the conversation never sees
  them until an event surfaces them.
- **THE REGIME**: the observe stamps work in the workspace regime (the third axis) as the
  Observation<Resource, Evidence> records of the managed resource, while the OS execution axis stays
  orthogonal. Operability is a RELATION (Binding), never an intrinsic file state.
- **THE DISTRIBUTION LAW**: the package keeps its own Config, ledger strings, and tools, and the
  recursion prevention makes every event carry the operation identifier, the parent identifier, and
  the event category.
- **THE TWINS**: the Classic and ETS twins follow the family contract.
